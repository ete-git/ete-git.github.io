# 概要
自分がこれまでに作成した制作物や創作物を掲載したポートフォリオサイトです。

## サイトURL
https://ete-git.github.io/

## 使用技術
- HTML
- CSS
- JavaScript
- Git / GitHub
- GitHub Pages

## 主な機能

- 制作物・創作物の一覧表示
- 作品の詳細情報の掲載
- JavaScriptによるページ演出
- 音楽の再生機能

## ディレクトリ構成
```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   ├── icon.png
│   ├── image-1.png
│   ├── image-2.png
│   ├── image-3.png
│   └── image-4.png
└── music/
    ├── Track-1.mp3
    ├── Track-2.mp3
    └── Track-3.mp3
```

## 工夫点
- **レスポンシブ対応**
  - PC・スマートフォンの両方で閲覧しやすいよう、画面幅に応じてレイアウトが変化するように設計

- **アニメーション**
  - スクロール時や再生時にアニメーションを取り入れ、視覚的にも楽しめるサイトを意識

- **見やすい色使い**
  - シンプルな色を採用し、情報を読み取りやすい配色を採用
